How it works

Smart searchSearches P/S, CNIC, H/S Code and Name as you type — instantly, with no upload per keystroke.
Tap to editSelecting a result loads the whole row into the form; Save writes it back to that same row.
New recordsIf no match exists, Save appends a new row and blocks duplicate P/S numbers.
Excel readyEvery changed or added row is highlighted yellow before download.
Everyone togetherThe file lives on the server; other people's changes appear here within a couple of seconds.
Nothing lostIf two people edit the same parcel you are shown both versions and choose which to keep.
